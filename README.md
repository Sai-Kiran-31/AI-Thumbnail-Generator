# AI Thumbnail Generator

A lightweight web app that generates stylized thumbnail images from a text prompt.

## Features

- Prompt-based thumbnail title generation
- Multiple visual styles (Modern, Neon, Minimal, Gaming)
- Aspect ratio options for common social/video formats
- One-click PNG download

## Run locally

Open `index.html` directly in your browser, or serve with a static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
